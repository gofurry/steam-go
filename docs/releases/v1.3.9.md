# v1.3.9 Release Notes

v1.3.9 adds Storefront release/language normalization, ResolveVanityURL, and
player profile asset helpers while preserving the existing raw API contracts.

## Highlights

- Added `NormalizeReleaseDate` with day, month, quarter, year, TBA, none, and
  unknown precision. Coarse dates expose inclusive UTC calendar ranges without
  inventing exact dates.
- Added the Steam language registry, alias lookup, canonical codes, and
  `ParseSupportedLanguages`, including three-state full-audio marker handling
  and unknown-language preservation.
- Added typed and raw `ISteamUser/ResolveVanityURL/v1` methods.
- Added player avatar discovery from official `GetPlayerSummaries` response
  URLs plus Verify / Read / Download helpers.
- Added equipped Profile background, mini-background, avatar-frame, animated
  avatar image, WebM, and MP4 discovery plus Verify / Read / Download helpers.
- Added optional `SteamID` metadata to the shared asset URL and result types,
  with propagation through success, failure, skip, and cancellation paths.

## Compatibility

- No breaking changes; all new public APIs and fields are additive.
- `SupportedLanguages string`, `ReleaseDate *StoreReleaseDate`, existing
  PlayerService types, and AppID asset behavior are unchanged.
- Unknown release text and languages produce fallback typed values rather than
  failing an otherwise successful Storefront response.

## Boundaries

- Avatar URLs are consumed directly from official
  `ISteamUser/GetPlayerSummaries/v2`; `avatarhash` is not used to guess URLs.
- Equipped Profile assets use the currently observed
  `IPlayerService/GetProfileItemsEquipped/v1` surface, which is not currently
  listed in Valve's public Web API reference.
- Profile helpers consume only Steam-returned absolute or protocol-relative
  URLs. They do not scrape Community HTML or infer CDN paths from item IDs.
- Badges and showcases receive no new asset-guessing layer in this release.
