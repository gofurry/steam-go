# v1.3.12 Release Notes — 草案

状态：**Unreleased / 未发布**。本文档用于准备兼容性热修，不代表本次工作已创建
v1.3.12 tag 或发布 GitHub Release。

## Highlights

- 新增 `storefront.AppDetailsMatch`、`ResolveAppDetails` 和
  `Service.GetResolvedAppDetails`，严格匹配请求 AppID 身份。
- 恢复 outer key 漂移时的 Storefront 媒体发现和免费 package 解析。
- Doctor 对安全解析的 key drift 显示带身份信息的 WARN；Fail 不增加，其他
  检查成功时退出码保持 0。
- Live smoke 与 Storefront 示例迁移到解析后的身份。

## Compatibility

公共 API 采用增量扩展，不计划引入破坏性变更。`GetAppDetailsRaw` 保留原始
bytes，`GetAppDetails` 保留原始 envelope key，`GetAppDetailsBatch` 保留公开
结构和逐项抓取错误语义。已有 envelope 可交给 `ResolveAppDetails`。

解析以 `data.steam_appid` 为依据。身份缺失、重复、匹配结果失败，以及 direct
key 的冲突或身份缺失均 fail closed，即使另有有效 entry 也不绕过。AppID 为 0
使用 `KindRequestBuild`，身份失败复用 `KindAPIResponse`；freeclaim 保持原有
verification 错误边界。

## Upstream Incident

[事故账本](../../governance/upstream-drift.md)记录 2026-09-26 AppDetails 的
已确认观测，并补录 2026-09-04 StoreBrowse `assets.last_modified` 类型漂移。
AppDetails 事故原因与 Valve 意图尚未确认，不能表述为官方契约已正式修改。

## Boundaries

本热修不重写 key、不直接取第一项、不推断 DLC/parent/child 关系，不新增
fallback endpoint 或抓取方式，也不修改 transport/retry/proxy/cache/rate-limit。
不修改 GoFurry。实时网络验证仅为显式启用的诊断，不是普通 CI 前置条件。

## Validation

已在本地 Go 1.27.1 验证：

- `web/storefront`、`addons/assets`、`addons/freeclaim`、`examples/doctor`、
  `examples/live` 及其子包的定向测试。
- `go test ./...`、`go test -race ./...`、`go vet ./...`。
- Go 1.26.8 的全量测试也已通过。
- 通过固定版本的 `go run` 命令运行 Staticcheck v0.8.1 和 govulncheck v1.3.0；
  未发现漏洞。
- `go run ./internal/tools/apidiffcheck -base v1.3.11 -incompatible`：
  无不兼容公共 API 变更。
- `go run ./internal/tools/steamapi-sync -output-dir docs/api`：
  63 个官方 endpoint、103 个 SDK endpoint，无实质 coverage drift；仅换行差异
  的生成文件改动已排除。
- `STEAM_GO_LIVE=1 go test ./examples/live/... -run '^TestLiveSmokeOptIn$' -count=1 -v`：
  显式启用的实时 smoke 通过。这是本次诊断结果，不构成 CI 网络前置条件，
  也不保证未来 Steam 可用性。

确定性回归保护包括精简的
`app_550_key_drift.json` fixture、完整 resolver 边界矩阵、Raw/typed 保真、
Batch 语义、addon 迁移、Doctor 退出行为，以及离线 live-smoke 身份测试。
