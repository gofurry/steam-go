# v1.3.9 Release Notes

v1.3.9 新增 Storefront 发行日期/语言规范化、ResolveVanityURL 和玩家 Profile
资源 helper，同时保留现有 raw API contract。

## Highlights

- 新增 `NormalizeReleaseDate`，覆盖 day、month、quarter、year、TBA、none、
  unknown；粗粒度日期提供 inclusive UTC calendar range，不伪造 exact date。
- 新增完整 Steam language registry、alias lookup、canonical code 和
  `ParseSupportedLanguages`，支持 full-audio 三态语义并保留未知语言。
- 新增 typed/raw `ISteamUser/ResolveVanityURL/v1`。
- 从 official `GetPlayerSummaries` 返回 URL 发现玩家头像，并提供
  Verify / Read / Download helper。
- 从已装备 Profile items 发现背景、迷你背景、头像框、动态头像图片、WebM 和
  MP4，并提供 Verify / Read / Download helper。
- 在共享 asset URL/result 类型中增加 optional `SteamID` metadata，并覆盖
  success、failure、skip、cancellation 全路径透传。

## Compatibility

- 无 breaking change；全部新 public API 和字段均为 additive。
- `SupportedLanguages string`、`ReleaseDate *StoreReleaseDate`、现有
  PlayerService 类型和 AppID asset 行为保持不变。
- 未知发行日期文本或语言会生成 fallback typed value，不会让已经成功的
  Storefront response 失败。

## Boundaries

- 头像 URL 直接消费 official `ISteamUser/GetPlayerSummaries/v2` 返回值，
  不根据 `avatarhash` 猜 URL。
- 已装备 Profile 资源使用当前 observed
  `IPlayerService/GetProfileItemsEquipped/v1` surface；Valve 当前公开 Web API
  reference 未列出该方法。
- Profile helper 只消费 Steam 返回的 absolute/protocol-relative URL，
  不抓 Community HTML，也不根据 item ID 推导 CDN path。
- 本版本不增加 badge 或 showcase asset guessing layer。
